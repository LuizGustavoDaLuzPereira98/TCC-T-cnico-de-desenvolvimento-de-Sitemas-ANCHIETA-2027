# TCC-T-cnico-de-desenvolvimento-de-Sitemas-ANCHIETA-2027
Feito para fins escolares, para complementação de curso.
🥾 Projeto: Jaguariaíva Aventura
A ideia seria criar uma plataforma onde a pessoa consegue descobrir, pesquisar e planejar visitas às trilhas, cachoeiras, parques e outros pontos de aventura de Jaguariaíva.

Funcionalidades principais
🗺️ Mapa interativo com os pontos turísticos

🔎 Busca por trilhas e atrações

🥾 Filtro por dificuldade: fácil, média e difícil

📏 Distância e duração estimada

💦 Filtro por tipo: cachoeira, trilha, mirante, parque etc.

📍 Localização do ponto

⭐ Avaliações dos visitantes

📸 Fotos

❤️ Favoritos

📝 Comentários

⚠️ Informações de segurança

👤 Cadastro/login

🛠️ Painel administrativo para cadastrar e editar atrações
